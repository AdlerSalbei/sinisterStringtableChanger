# Sinister Inc. Stringtable Changer
Changes Star Citizens stringtable to add Sizes, Types and other information.

# Naming format
The format is: **[Component Name] [Size] [Type] [Quality] [Optional: Sinister Needs]**
Example: `TS-2` → `TS-2 S3 Military A EHD`

**Optional abbreviation:**
- **EHD** = Extremely high demand
- **HD** = High demand
- **ND** = Normal demand
- **ZD** = Zero demand
### Alternate

The format is: **[Type][Size][Quality] [Component Name] [Optional: Sinister Needs]**
Example: `TS-2` → `M3A TS-2 EHD`

**Type abbreviations:**
- **M** = Military
- **I** = Industrial
- **C** = Civilian
- **R** = Racing (Competition renamed to avoid conflict with Civilian)
- **S** = Stealth
